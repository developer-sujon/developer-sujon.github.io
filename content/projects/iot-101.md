## Overview

**IOT-101** ([GitHub Repository](https://github.com/developer-sujon/IOT-101)) is an open-source collection of embedded systems, robotics experiments, and Internet of Things (IoT) sensor automation pipelines. It demonstrates practical sensor interfacing, hardware GPIO control, serial bus communication, and webhook-driven cloud automations using **n8n**.

The collection covers critical real-world industrial and smart-home applications—such as kitchen gas leak detection with active buzzer alerts, environmental climate monitoring, serial telemetry streaming, and automated event triggers.

---

## Key Hardware Modules & Experiments

* **Kitchen Safety Automation (Gas Leak Detection):** Interfaced the **MQ-6** semiconductor sensor for LPG/isobutane/propane detection. Evaluates analog threshold values in real time to trigger emergency LED indicators, piezoelectric buzzers, and automated notification webhooks.
* **Environmental Climate Monitoring (Heat Wave Alert):** Interfaced **DHT11** temperature and humidity sensors with digital sampling routines, computing heat index values for proactive climate warnings.
* **Serial Telemetry & Communication:** Implemented bidirectional serial communication protocols between microcontrollers and host servers, streaming sensor telemetry for cloud ingestion.
* **Smart Lighting & PWM Actuation:** Built pulse-width modulation (PWM) routines for breathing LED transitions, LDR-based ambient light detection for automatic street lighting, and multi-state push-button state machines.
* **Infrared Telemetry (IR Decoding):** Decoded 38kHz infrared remote control signals using pulse-timing analysis to remotely trigger relay actuators and appliances.

---

## Cloud Integration & n8n Workflow Automation

Beyond standalone microcontroller firmware, the project explores hardware-to-cloud integrations:

* **Event-Driven n8n Pipelines:** Microcontroller telemetry events connect to **n8n workflow automations** via HTTP webhooks and MQTT brokers.
* **Automated Alerting:** Sensor thresholds (e.g., gas concentration exceeding safety thresholds) trigger automated notifications to Telegram channels, email alerts, and incident logs without human intervention.
* **Self-Hosted Infrastructure:** Designed to run on lightweight local gateways (Raspberry Pi or mini-PCs) connected to cloud dashboards.
